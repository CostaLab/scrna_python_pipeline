We install packages for the analysis of single cell RNA seq data.

1) Unload the typically loaded modules.
module unload scRNA
module unload R

# 2) Activate conda.
# conda activate

3) Create the environment single_cell_pipeline_python.
# harmonypy must either be installed using conda or pip.
unset PYTHONPATH # The variable has caused problems. 
conda create -n single_cell_pipeline_python_3_11 python=3.11 -y
conda activate single_cell_pipeline_python_3_11
conda install --strict-channel-priority -c conda-forge -c bioconda \
  numpy=1.24 pandas scanpy scikit-learn matplotlib seaborn pyyaml \
  harmonypy python-igraph leidenalg statsmodels cython setuptools wheel bbknn \
  polars cyvcf2 pyarrow pydantic numba tqdm 'scvi-tools>=1.0' openpyxl -y
python -m pip install --no-cache-dir scikit-misc scrublet xlsxwriter scib-metrics

4) Now, I add decontX-python. This is not part of the original pipeline, but become necessary after the demultiplexing of the
new MF samples. We should estimate the ambientRNA to demultiplex the samples using vireo.
First, we install some dependencies for decontx-python so that they are tracked by conda. Then we install decontx-python using pip.
Since pip will also want to install dependencies this could lead to the environment breaking. This way, we prevent this.
# conda install -c conda-forge numba tqdm -y # Already installed above.
pip install decontx-python --no-deps

5) So, we can easily reconstruct the environment, I export it. Just to be save.
conda list gives us a specific list of the packages with URL and exact build.

conda env export -n single_cell_pipeline_python_3_11 --file single_cell_pipeline_python_3_11.yaml
conda list --explicit -n single_cell_pipeline_python_3_11 > single_cell_pipeline_python_explicit_3_11.txt
